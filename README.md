# AIC354 Assignment 2 — End-to-End Machine Learning Systems

This submission contains two executed Jupyter notebooks and a combined Streamlit app. It uses the instructor's Titanic teaching sample and the official UCI Cleveland Heart Disease dataset.

## Files

- `notebooks/Titanic_Passenger_Survival.ipynb` — preprocessing, label encoding, SVC training, 80/20 evaluation, one passenger prediction, and trained bundle export.
- `notebooks/Heart_Disease_Prediction.ipynb` — same stages using exactly four input features (`age`, `sex`, `cp`, `thalach`), with a stratified 80/20 split. Original target `num=0` is mapped to **No disease**; `num=1,2,3,4` are mapped to **Disease present**.
- `data/sample-data.csv`, `data/heart_disease.csv` — both source datasets.
- `titanic_model.pkl`, `heart_disease_model.pkl` — trained model bundles with encoders and feature order, saved by the notebooks and loaded by the app.
- `app.py`, `model_utils.py`, `requirements.txt` — combined prediction app, model-loading helpers, and dependencies.

## Run locally

```powershell
py -m venv .venv
.venv\Scripts\activate
py -m pip install -r requirements.txt
py -m notebook
```

Open each notebook and choose **Kernel → Restart Kernel and Run All Cells**. The saved outputs in this submission are from completed execution. Then launch the app from this folder:

```powershell
py -m streamlit run app.py
```

The app provides Titanic and Heart Disease forms. Inputs use bounded dropdowns/sliders and the app loads the model bundles generated by the notebooks.

## Deployment

The app is ready for Streamlit Community Cloud with `app.py` as its entry point. Deploy from the public GitHub repository, then replace the deployment placeholder at the top of both notebooks with the verified public app URL. No live URL is included until that deployment has been created and checked.

## Interpretation and safety

Titanic results use a 100-row teaching sample and are for demonstrating workflow only. The heart model is a classroom exercise using four fields from a small historical dataset. It is **not a medical diagnostic tool** and must not be used for medical decisions.

Dataset sources and attribution are recorded in `data/DATA_SOURCES.txt`.
